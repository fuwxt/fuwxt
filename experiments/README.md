# Experiments

This folder is a sandbox space for small experiments, drafts, and notes that don't belong on the main portfolio site.

Nothing here is wired into `index.html`, so the live site at [fuwxt.github.io](https://fuwxt.github.io) stays untouched.

## Contents

- `README.md` — this file
- `notes.md` — quick notes & ideas
- `todo.md` — running todo list
- `links.md` — useful resources

## Why

A safe place to iterate on:
- New design ideas before they go live
- Documentation drafts
- Snippets and references
